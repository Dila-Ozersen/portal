# PORTAL
An in-progress, open-source workplace collaboration platform for teams, projects, and any shared workspaces.

# Planned Features
- Company and personal workspaces
- Teams and team-based project management
- Task and project collaboration between users
- Shared calenders
- Direct and group messaging
- Rolse-based access control

# Tech Stack
- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- Database access: pg with SQL migrations
- Version control: Git and GitHub

# Project Status
- Currently in initial setup and planning stage. More documentation will be added as development progresses.
